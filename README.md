# Документация проекта: Виджет банковских операций клиента
## О проекте
Проект представляет собой набор функций для обработки и отображения банковских операций клиента. 
Основные возможности включают маскировку конфиденциальной информации, 
фильтрацию и сортировку операций.
## Установка:
### Требования:
- Python 3.8+
## Функции
## Модуль masks.py
### get_mask_card_number
Частично маскирует номер банковской карты.
#### Параметры:
- `card_number`(str): номер карты
#### Возвращаемое значение:
- str: замаскированный номер карты
#### Пример:
```
>>> get_mask_card_number("4000123456789012")
'4000 12** **** 9012'
```
### get_mask_account
Маскирует номер банковского счета.
#### Параметры:
- `account_number`(str): номер счета
#### Возвращаемое значение:
- str: замаскированный номер счета
#### Пример:
```
>>> get_mask_account("Счет 40817810000000000000")
'Счет **0000'
```
## Модуль widget.py
### mask_account_card
Маскирует одновременно номер счета и карты.
#### Параметры:
- `account_number`(str): номер счета
- `card_number`(str): номер карты
#### Возвращаемое значение:
str: (замаскированный номер счета или замаскированный номер карты)
#### Пример:
```
>>> mask_account_card("Visa Platinum 7000792289606361")
("Visa Platinum 7000 79** **** 6361")

>>> mask_account_card("Счет 73654108430135874305")
("Счет **4305")
```
### get_date
Форматирует дату в нужный формат.
#### Параметры:
- `date_str`(str): строка с датой в формате ISO
#### Возвращаемое значение:
- str: отформатированная дата в формате дд.мм.гггг
#### Пример:
```
>>> get_date("2024-03-11T02:26:18.671407")
"11.03.2024"
```

## Модуль generators.py
### Описание
Модуль содержит вспомогательные функции для работы с транзакциями и генерацией номеров карт.
### Функции модуля
### 1. filter_by_currency
#### Назначение:
Фильтрация транзакций по валюте.
#### Параметры:
`transactions` (list) - список операций
'currency' (str, опционально) - код валюты (по умолчанию 'USD')
#### Возвращаемое значение
Список транзакций, отфильтрованных по указанной валюте
#### Пример использования:
```
transactions = [
    {"operationAmount": {"currency": {"code": "USD"}}},
    {"operationAmount": {"currency": {"code": "EUR"}}}
]

usd_transactions = filter_by_currency(transactions, "USD")

```
### transaction_descriptions
#### Назначение:
Генерация описаний транзакций
#### Параметры:
`transactions` (list) - список транзакций
#### Возвращаемое значение:
Генератор строк с описаниями транзакций
#### Пример использования:
```
transactions = [
    {"description": "Покупка в магазине"},
    {"description": "Оплата услуг"}
]

descriptions = transaction_descriptions(transactions)
for desc in descriptions:
    print(desc)
```
### card_number_generator
#### Назначение:
Генерация форматированных номеров карт
#### Параметры:
`start` (int) - начальное значение диапазона
`end` (int) - конечное значение диапазона
#### Возвращаемое значение:
Генератор форматированных номеров карт в формате XXXX XXXX XXXX XXXX
#### Особенности:
* Проверяет корректность входных данных
* Форматирует номера в группы по 4 цифры
* Генерирует последовательность номеров
#### Пример использования:
```
gen = card_number_generator(1234567890123456, 1234567890123458)
for number in gen:
    print(number)
```
#### Возможные ошибки:
`TypeError` - при передаче нечисловых значений
`ValueError` - если начальное значение больше конечного

## Модуль decorators.py
### декоратор `log`
### Описание
Декоратор для логирования выполнения функций с возможностью записи в файл.
### Основные возможности
* **Логирование ошибок**: автоматически фиксирует тип ошибки и входные параметры
* **Запись в файл**: возможность сохранять логи в указанный файл
* **Консольный вывод**: при отсутствии файла логи выводятся в консоль
* **Универсальность**: работает с функциями любого количества аргументов
### Установка и использование
```
from src.decorators import log
```
### Пример использования
```
@log(filename="app.log")
def add_numbers(a: int, b: int) -> int:
    return a + b

add_numbers(3, 5)  # Запишет успешный результат в лог
add_numbers("3", 5)  # Запишет информацию об ошибке
```
### Параметры декоратора
| Параметр |    Тип    |                                   Описание                                   |
|----------|:---------:|:----------------------------------------------------------------------------:|
| filename | str, None | Путь к файлу для записи логов. <br/>Если не указан, логи выводятся в консоль |
### Примеры логов
```
# Успешное выполнение
add_numbers ok

# Ошибка выполнения
add_numbers error: TypeError. Inputs: '3', 5
```
## Модуль scv_excel_reader.py
### Функция csv_reader
Функция для чтения данных из CSV-файлов и преобразования их в список словарей.
### Описание:
Функция принимает путь к CSV-файлу и возвращает данные в формате списка словарей, 
где каждый словарь представляет собой строку из файла.
### Параметры:
`path`(str) — путь к CSV-файлу
### Возвращаемое значение:
* list[dict] — список словарей с данными из файла
* str — сообщение об ошибке, если произошла ошибка при чтении файла
### Возможные ошибки:
* FileNotFoundError — если файл не найден
* ValueError — если расширение файла не CSV
* Общая ошибка — при других проблемах чтения файла
### Пример использования:
```
data = csv_reader('data.csv')
print(data)  # [{'column1': 'value1', 'column2': 'value2'}, ...]
```
### Функция excel_reader
Функция для чтения данных из Excel-файлов и преобразования их в список словарей.
### Описание:
Функция принимает путь к Excel-файлу и возвращает данные в формате списка словарей, 
где каждый словарь представляет собой строку из файла.
### Параметры:
`path`(str) — путь к Excel-файлу
### Возвращаемое значение:
* list[dict] — список словарей с данными из файла
* str — сообщение об ошибке, если произошла ошибка при чтении файла
### Возможные ошибки:
* FileNotFoundError — если файл не найден
* ValueError — если расширение файла не XLSX
* Общая ошибка — при других проблемах чтения файла
### Пример использования:
data = excel_reader('data.xlsx')
print(data)  # [{'column1': 'value1', 'column2': 'value2'}, ...]
### Рекомендации по использованию:
* Убедитесь, что файлы существуют перед чтением
* Проверяйте расширения файлов перед передачей в функции
* Обрабатывайте возможные ошибки при работе с функциями
* Используйте корректные пути к файлам
