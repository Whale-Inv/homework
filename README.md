# Документация проекта: Виджет банковских операций клиента

## О проекте
Проект представляет собой набор функций для обработки и отображения банковских операций клиента. 
Основные возможности включают маскировку конфиденциальной информации, 
фильтрацию и сортировку операций.
## Установка:
### Требования:
- Python 3.8+
## Использование
### Импорт модуля
```
from banking_widget import (
    get_mask_card_number,
    get_mask_account,
    filter_by_state,
    sort_by_date,
    mask_account_card,
    get_date
)

```
## Функции
### Маскировка данных
### get_mask_card_number
Частично маскирует номер банковской карты.
#### Параметры:
- `card_number`(str): номер карты
#### Возвращаемое значение:
- str: замаскированный номер карты
#### Пример:
```
>>> get_mask_card_number("4000123456789012")
'4000 12** **** 9012'
```
### get_mask_account
Маскирует номер банковского счета.
#### Параметры:
- `account_number`(str): номер счета
#### Возвращаемое значение:
- str: замаскированный номер счета
#### Пример:
```
>>> get_mask_account("Счет 40817810000000000000")
'Счет **0000'
```
### mask_account_card
Маскирует одновременно номер счета и карты.
#### Параметры:
- `account_number`(str): номер счета
- `card_number`(str): номер карты
#### Возвращаемое значение:
str: (замаскированный номер счета или замаскированный номер карты)
#### Пример:
```
>>> mask_account_card("Visa Platinum 7000792289606361")
("Visa Platinum 7000 79** **** 6361")

>>> mask_account_card("Счет 73654108430135874305")
("Счет **4305")
```
### Работа с операциями
### filter_by_state
Фильтрует список операций по состоянию.
#### Параметры:
- `transaction_data`(list): список словарей с операциями
- `state`(str, опционально): значение состояния для фильтрации (по умолчанию ‘EXECUTED’)
#### Возвращаемое значение:
- list: отфильтрованный список операций
#### Пример:
```
>>> [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

# Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

>>> [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

# Выход функции, если вторым аргументов передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
### sort_by_date
Сортирует список операций по дате.
#### Параметры:
- `operation_list`(list): список словарей с операциями
- `reverse_sort`(bool, опционально): флаг сортировки (True - по убыванию, False - по возрастанию)
#### Возвращаемое значение:
- list: отсортированный список операций
#### Пример:
```
>>> [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

# Выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```
### get_date
Форматирует дату в нужный формат.
#### Параметры:
- `date_str`(str): строка с датой в формате ISO
#### Возвращаемое значение:
- str: отформатированная дата в формате дд.мм.гггг
#### Пример:
```
>>> get_date("2024-03-11T02:26:18.671407")
"11.03.2024"
```
